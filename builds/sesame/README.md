# Sesame build

My build of [Sesame](https://github.com/dorianborian/sesame-robot), a small ESP32 quadruped with 2 servos per leg.

Nothing here yet. This folder will hold:

- `firmware/`: code running on the ESP32-S2 Mini
- `schematics/`: wiring and perfboard layout
- `stl/`: 3D-printed parts (and any changes I make to them)
- `photos/`: the build, step by step

Parts: see the [BOM](../../bom.csv). Simulation side: see the [course notes](../../course/01-mujoco-foundations.md#sesames-kinematic-tree).
